# Growthline — Creating a Marketing Plan

Адаптивный одностраничный сайт по заданию на вёрстку.

## Структура
- `index.html` — разметка страницы.
- `style.css` — стили и мобильная адаптация.
- `script.js` — мобильное меню и автоматический год в подвале.

## Запуск
Откройте `index.html` в браузере. Сборка и дополнительные библиотеки не нужны.

## Публикация на GitHub Pages
1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
4. После публикации сайт будет доступен по адресу:
   https://pervisprogram.github.io/marketing-plan-site/
